# ANTI-RABBIT-HOLE PRINCIPLES

## Core Principle

> **"The system must never become a major consumer of the time it is designed to protect."**

---

## 1. Foundational Rules

1. **The system exists to reduce cognitive load.** It provides clarity and calm, not endless data points or micro-decisions.
2. **The system is not intended to maximize productivity.** It exists to protect balance across Health, Spiritual Practice, Family, Trading, HIFY, Content, and Job Transition.
3. **No feature for vanity.** Metrics that stroke the ego but do not produce concrete outcomes (e.g., social follower counts, arbitrary streaks) are excluded.
4. **No gamification.** No badges, experience points, celebration confetti, leveling up, or artificial dopamine triggers.
5. **No unnecessary dashboards.** Information is consolidated into a single calm executive view. No multi-tab analytics mazes.
6. **No minute-by-minute time tracking.** No stopwatch timers, Pomodoro clocks, or second-by-second activity recording. Coarse weekly estimates and binary commitments are preferred.
7. **No live market terminal.** No real-time ticker feeds, price streaming, or intraday charts. Weekend review and planned allocations only.
8. **No automated trading execution.** No broker API integrations, automated orders, or algorithmic black boxes. Decisions remain manual, thoughtful, and planned.
9. **No unnecessary notifications.** No desktop pings, system tray alerts, push notifications, or nagging reminders. Interaction is initiated intentionally by the user.
10. **No infinite backlog.** The system rejects bottomless task buckets. Tasks are either scheduled in this week's 3–5 commitments, part of the finite website checklist, or rejected.
11. **No feature merely because it is technically interesting.** Technological novelty (e.g., local LLM daemons, complex graph databases, native plugins) is forbidden unless it directly reduces user effort.
12. **Website/product work must remain bounded.** The HIFY website has a finite checklist (Core, Conversion, Experience, Polish). Polish must never delay entering maintenance freeze mode.
13. **New strategy experimentation must remain intentionally controlled.** Trading research is bounded to the defined universe and weekend review cycle. No impulsive exploratory pipelines during operating weeks.
14. **The tracking system itself must not become a major time consumer.** If maintaining this software begins encroaching on work, health, or family, the system has failed its core mission.

---

## 2. Explicit Non-Goals (Strictly Forbidden Scope)

Under no circumstances should the following features be built into this codebase:

- **Habit streak system** (streaks generate guilt, induce anxiety when traveling or sick, and distort genuine intention).
- **Gamification or arbitrary productivity scores** (arbitrary numbers encourage gaming the metric).
- **Minute-by-minute time trackers or Pomodoro clocks**.
- **Live market feeds, price tickers, or trading terminals**.
- **Automated broker execution or algorithmic order placement**.
- **Trading alerts or speculative market scrapers**.
- **Cloud authentication, JWT tokens, or multi-user SaaS architecture**.
- **Push notifications, browser alarms, or mobile push services**.
- **Social media management tools or auto-publishing pipelines**.
- **Full calendar replacement or scheduling engines**.
- **AI life coach or autonomous behavioral recommendation generators**.
- **Complex analytics platforms or statistical modeling charts**.
- **Feature marketplace, plugin registry, or modular extension stores**.
- **Infinite task backlogs or sprawling Kanban boards**.

---

## 3. Strict Interaction Budget

The software must be designed so that interaction requires minimal human time:

| Interaction Window | Maximum Allowed Budget | Focus |
| :--- | :--- | :--- |
| **Daily** | **2 – 5 minutes maximum** | Quick check of today's focus; log daily health check if desired. |
| **Weekly** | **15 – 20 minutes** | Enter weekly actuals, review drift indicators, select next week's 3–5 commitments, set "NOT DOING" list. |
| **Fortnightly** | **~30 minutes** | Answer the 9 review questions, audit drift, export review prompt to ChatGPT, adjust next fortnight's guardrails. |

If any design proposal threatens to push the user past these budgets, the proposal must be simplified or scrapped. The system strongly favors **manual, deliberate, low-frequency input** over **automatic, continuous, high-frequency tracking**.

---

## 4. Calm Executive Control Panel Standard

The visual interface must evoke the feel of an executive flight deck or a quiet study:
- **Calm over urgency:** Muted, neutral palettes; no flashing warnings or aggressive red banners.
- **Whitespace & readability:** Clean typography, generous spacing, high contrast, zero visual clutter.
- **Objective drift signaling:** Drift is presented as neutral divergence (e.g., *"Website hours (12h) exceeded planned allocation (5h)"*), not personal condemnation (*"You failed"*).
