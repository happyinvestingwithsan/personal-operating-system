───────────────

       │                Content (YT/IG) → Masterclass → Cohort → Pathfinder
       ▼
       ⚠️ BOUNDED / FINITE LAYER: WEBSITE INFRASTRUCTURE (Nexus completion → FREEZE)

### The Attention Allocation Rule
- **Morning Peak Hours (4:30 AM – 7:30 AM):** Dedicated strictly to Tier 1 (Kriya + Exercise) and Tier 4 high-leverage planning (Content ideation). No website coding during this window unless explicitly planned for a designated infrastructure block.
- **Evening Boundary:** Hard shutdown on screen work to protect 4:30 AM wakeup.
- **Weekend Container:** 
  - 1 protected half-day for Family (zero screens/work).
  - 1 bounded slot (2–3 hrs) for Trading Review & Portfolio Decisions.
  - Remaining time for Cohort/Pathfinder or bounded tasks.

## 3. Four-Tier Taxonomy: Goal vs. System vs. Commitment vs. Task

To eliminate task-list clutter, the system strictly separates these four concepts:

```
[GOAL]        What we want to achieve long-term (Outcome)
  │           e.g., "Move weight toward 70-74 kg with physical strength"
  ▼
[SYSTEM]      The recurring loop that guarantees the outcome
  │           e.g., "Morning routine: 4:30 wake -> Kriya -> Strength workout 4x/week"
  ▼
[COMMITMENT]  What we declare we WILL do in a given week (Binary accountability)
  │           e.g., "Complete 4 strength sessions and 6 Kriya sessions this week"
  ▼
[TASK]        An atomic action to fulfill a commitment
              e.g., "Prepare workout gear Sunday evening"
```

The system manages **Goals, Systems, and Commitments**. It intentionally does **NOT** attempt to be a micro-task manager.

The system automatically identifies divergences between planned attention and actual execution:

## 7. The Website Freeze Protocol

Because product development is the primary historical vector for priority dilution, the system tracks website work inside a dedicated **finite container**:

1. **Backlog is Capped:** Only items in categories `CORE` (infrastructure) and `CONVERSION` (public tools $\rightarrow$ masterclass) are permitted.
2. **Items Categorized as `POLISH`:** Automatically deferred unless all Core items are done.
3. **The Freeze Gate:** When all Core + agreed Conversion items reach 100%:
   - The status switches to **MAINTENANCE ONLY**.
   - No new website items can be created without passing the strict Change Control Gate (Section 37 of specification).
